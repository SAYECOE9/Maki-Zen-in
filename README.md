## ⚡ Key Features

- **🔴 Cyber-Crimson Visuals:** Custom dark radial mesh background layered with high-intensity red neon glow effects (`glow-red-text`, `glow-circle`).
- **🈲 Authentic Kanji Integration:** Features Japanese `Noto Sans JP` typography rendering traditional Kanji (`禪院` - *Zen'in*) alongside futuristic headers (`Orbitron`, `Rajdhani`).
- **⚡ Zero-Build Setup:** Pure HTML & Tailwind CSS via CDN with Font Awesome 6 icons. Zero `npm` packages or build pipelines required.
- **📱 Fully Responsive Design:** Clean layout adaptivity across desktop, tablet, and mobile viewports with smooth hover micro-interactions.
- **🗡️ Glassmorphism & Micro-animations:** Styled action buttons with backdrop filters, subtle depth shadows, and interactive state triggers.
